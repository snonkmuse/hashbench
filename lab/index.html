Permissions & PWA Lab

Local-only test lab. Nothing on this page is recorded, uploaded, or sent anywhere — every result stays in this tab. Browsers only hand out camera, microphone, files, and location after you click and approve, so nothing here prompts on load: each test runs only from its button. Camera/mic streams are never recorded and stop themselves after 15 seconds. File tests read metadata only (name, size, type) of files you pick — never contents. Clipboard read reports only the length of what's there.
