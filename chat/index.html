Direct Chat

Peer-to-peer chat between two browsers, using a WebRTC data channel. There is no chat server: this page is static, messages travel directly between the two browsers, encrypted by the data channel's DTLS. Nothing is stored anywhere — close the tab and the conversation is gone.

How the connection is made without a server: one side creates an invite code, the other side pastes it and produces an answer code, the first side pastes the answer. Those codes are connection descriptions (SDP) — they contain network addresses, because that's how the two browsers find each other. Treat a code like a phone number: share it only with the person you mean to chat with. A public STUN server (Google's) is used only to discover your public address for NAT traversal; it never sees message content.
