RandomX Browser Benchmark

The real Monero proof-of-work algorithm (RandomX v1), compiled to WebAssembly and run entirely in this page — no pool, no wallet, nothing is mined or submitted anywhere. Configuration is deliberately the slowest stock one: light mode (256 MiB cache, no 2 GiB dataset), interpreted VM (no JIT), software AES, 1 thread. Native miners use fast mode + JIT + hardware AES and are much faster; the reference numbers under the controls show both kinds.
